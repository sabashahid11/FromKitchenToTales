# Frontend Flow to implement
1 -> User authenticate (signin, signup routes) 
2 -> camera screen ( use /upload-image provide the captured image in base_64 string )
3 -> list of recipes ( /recipe-list route to get all the recipes from detecting ingredients from image )
4 -> steps screen ( /recipes-content to generate steps )
5 -> user can save by using /save-recipe route
6 -> user can give reviews by /give-review 
7 -> view saved recipes screen (/fetch-recipes)
8 -> settings screen (/update user to update user info, baaki language change frontend say dekhlena)
